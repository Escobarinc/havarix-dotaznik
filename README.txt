GitHub Pages:
1. Nahrajte obsah této složky do kořene GitHub repozitáře.
2. GitHub > Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: / (root).
5. Uložte a po chvíli otevřete vygenerovanou GitHub Pages adresu.

Dotazník ukládá průběh do localStorage v prohlížeči klienta.
Na konci lze odpovědi stáhnout jako TXT nebo JSON a také vytisknout / uložit do PDF.
